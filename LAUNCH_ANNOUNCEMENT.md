# LuminOS — project status (pre-alpha)

LuminOS is a lean CachyOS/Arch-based distribution with a single **Glass** (Hyprland) flavor under active development.

### Phase 1 (current)

- Honest documentation and CI
- Lean Glass ISO profile using CachyOS repos and `linux-cachyos`
- Compile-clean `lumin-*` helpers (Windows runners intentionally stubbed)

### Phase 2 (planned)

- Seamless Windows app support via Wine-GE/Proton
- Optional Bubblewrap sandbox and desktop integration

### Not claimed yet

We are not claiming custom kernel forks, four shipping editions, DistroWatch readiness, or measured “Windows killer” benchmarks until those exist and are verified.
