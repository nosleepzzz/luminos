Universal Lightweight Core Architecture

⚡

Universal Ultra-Low RAM

Starts under 280 MB – 420 MB idle RAM. ZRAM memory compression allows low-RAM computers to run smoothly without disk swapping.

🔋

Native Power Daemon

lumin-powerd automatically switches CPU governors and enables PCIe ASPM C8/C10 deep C-states on battery power.

🌀

BORE Kernel Scheduling

Custom linux-lumin 6.10.5 kernel with BORE & eBPF sched_ext for ultra-low frame latency during high background loads.

🛡️

Bubblewrap EXE Sandboxing

Run Windows .exe binaries in unprivileged Bubblewrap (bwrap) sandbox containers with DXVK Vulkan acceleration (lumin-security --sandbox).

🍏

macOS Sonoma Glass UX

Beautiful Wayland desktop environment with multi-touch touchpad gestures (3-finger swiping) and macOS traffic light controls.
